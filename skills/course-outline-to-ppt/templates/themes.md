# 视觉主题画廊（供用户选择）

> 生成课件前，从下面 6 套主题里选一套作为整份 PPT 的视觉基调。每套主题是一组完整的配色 + 字体 + 视觉母题预设，**全部为实色配色，刻意规避紫渐变、深蓝霓虹等 AI-slop 组合**。
>
> 机器可读定义见同目录 `themes.json`；生成器调用见 `themes.py`。

## 怎么选

1. **用户已指定风格**（"要科技感""暖一点""商务汇报用"）→ 按下表直接匹配，不必再问。
2. **用户没指定** → 用 AskUserQuestion 给 3 个最贴合主题方向的选项让用户挑（参考 huashu 的"给用户看得见的方向"原则），默认推荐按课程主题自动匹配的那套。
3. **拿不准** → 用 `deep-space`（最通用）。

## 配色角色说明（所有主题通用）

| 角色 | 用途 |
|------|------|
| dominant | 标题、章节眉标深色块、封面/总结背景 |
| deep | 封面更深底色（与 dominant 叠用增层次） |
| support1 | 深色底上的浅字（封面副标题） |
| support2 | 内容卡片浅底 |
| panel | 深色卡片/表头次级块 |
| row_alt | 表格隔行底 |
| accent | 主强调色：火花、编号、左色条、关键标注 |
| accent2 | 辅助强调色：第二色条、对比栏/交替步骤 |
| ink | 正文主色 |
| muted | 副线/说明灰字 |

## 反 AI-slop 约定

- 全部主题为**实色**配色，不使用紫渐变、均匀深蓝+霓虹 glow 等烂大街组合
- 强调色每套都带明确意图（琥珀火花/古铜金/赤陶/香槟金/珊瑚/玫瑰铜），不是通用蓝
- 配色只是基调；页面"厚度"仍由 content-density.md 的主副点分层与可视化版式保证
