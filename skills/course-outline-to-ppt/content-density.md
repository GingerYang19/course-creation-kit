# 课件内容密度与丰富度指南

> 目标：每页既要"信息充足"又要"重点清晰"。通过**主副点分层 + 图解表格 + 案例场景**三类手段，让每页摆脱"几条干要点"的单薄感，达到专业培训课件的厚度。

## 每页文字量规范

| 页面类型 | 标题 | 主体结构 | 页面总文字量 |
|----------|------|----------|--------------|
| 封面页 | 课程名 ≤12字 | 副标题 1 条 ≤25字 | ≤50字 |
| 目录页 | "目录" | 章节列表，每项 ≤16字 | ≤120字 |
| 章节分隔页 | 章节名 ≤10字 | 引导语 1 条 ≤30字 | ≤50字 |
| 内容页（分层） | ≤18字 | 3-5 组「主点+副线」 | 160-320字 |
| 图解/表格页 | ≤18字 | 图示/表格 + 2-4 条标注 | 120-260字 |
| 总结页 | ≤10字 | 3-5 条回顾 | 80-180字 |

**核心变化**：内容页不再写"单行要点"，而是写「主点 + 副线」的分层结构，总文字量上限提到 320 字，但通过分层与可视化保持可读。

## 主副点分层写法（默认结构）

每个知识点由两层组成：

- **主点**：动词开头的短语，一行讲清"是什么/做什么"（15-30字）
- **副线**：紧跟主点，用解释、案例、数据或场景把主点撑起来（20-45字）

### 好的分层示例

```
主点：理解最小权限原则，按需授权
副线：只开放完成任务所需的最小文件与操作范围，避免一次给满权限

主点：掌握短期与长期记忆的分工
副线：短期记忆守住当前任务上下文，长期记忆沉淀跨会话的偏好与经验

主点：应用渐进授权建立协作信任
副线：先让 Agent 做只读汇总，确认可靠后再放开写操作与自动执行
```

### 避免的写法

```
✗ 只有主点没有副线（单薄，回到旧问题）
✗ 副线只是把主点换词重复一遍（无新增信息）
✗ 主点副线写成一大段完整句子（应拆成两层短语）
```

## 案例与场景行规则

- 每个内容页**至少 1 条**要点带场景化例子或类比，副线中用"例如/比如/就像"引出
- 案例要贴近受众工作场景（企业培训用办公/业务场景，技术类用工程场景）
- 不编造精确数字与真实公司案例；用概数（"超过七成""数倍"）或泛指场景（"一家电商团队""财务同学"）
- 类比优先用受众熟悉的事物解释抽象概念（如"记忆就像同事的工作笔记"）

## 图解与表格选用指南

每 2-3 页内容页中，**至少安排 1 页**用可视化结构替代纯要点。版式与 python-pptx 实现见 pptx 技能 `references/python_pptx_recipes.md`。

| 内容特征 | 推荐版式 | 说明 |
|----------|----------|------|
| 两个对立/并列概念 | 对比双栏 / Before-After | 如"云端大脑 vs 本地躯体""人工 vs 自动" |
| 有先后顺序的流程 | 编号步骤 / 时间线 + 箭头 | 如"任务协同闭环""进化路径" |
| 多个并列分类 | 多列卡片（2-4 列） | 如"电商/财税/制造三领域" |
| 关键数字/结论 | 数据卡片 / 大字报 | 概数为主，突出一个核心量级 |
| 多维属性对照 | 表格（行=对象，列=维度） | 如三类记忆的"作用/时长/示例"对照 |
| 层级/包含关系 | 嵌套框图 / 同心结构 | 如"权限的三层边界" |

**表格使用要点**：
- 行数 ≤5、列数 ≤4，单元格文字 ≤12字
- 表头用主导色填充白字，首列可加粗
- 表格上方给一句"读表引导"，下方给 1-2 条结论标注

## Bullet 通用规则

- 动词开头：掌握 / 理解 / 应用 / 区分 / 建立 / 实现
- 一条一个知识点，不复合
- 数据用概数，除非参考资料给出精确数字
- 避免"很重要""第一点第二点"这类无信息量或应靠结构表达的写法

## 页面间逻辑编排

### 教学递进结构

```
章节分隔页（引出主题）
→ 概念定义页（是什么，分层要点）
→ 原理/对比页（为什么，对比双栏或框图）
→ 方法/流程页（怎么做，编号步骤）
→ 案例/应用页（实际场景，多列卡片或场景行）
→ [可选] 数据/总结页（数据卡片或对照表）
```

### 页数分配策略

每个大纲章节按内容复杂度分配：
- 简单概念：1-2 页
- 中等内容：2-3 页
- 复杂主题：3-4 页

丰富度优先于页数：当用户给定页数偏少时，优先保证每页"分层 + 至少一处可视化或案例"，而不是把内容稀释成单行要点。

## 参考资料融合规则

1. 参考资料中的专业表述、数据、案例 → 直接引用，保留原文
2. 参考资料覆盖的章节 → 以参考资料为主要内容来源
3. 参考资料未覆盖的章节 → 用通用知识补充，标注 [补充]
4. 参考资料与大纲结构不完全对应 → 按大纲结构重组参考资料内容
5. 多份参考资料冲突 → 取最新/最权威的，或并列呈现

## 更新课件时的搜索策略

搜索关键词组合（至少 2-3 组）：
- "{课程主题} 2026 最新进展"
- "{课程主题} 案例 实践"
- "{课程主题} 趋势 变化"
- "{具体章节关键词} 新方法 新工具"

筛选标准：
- 时间：优先近 12 个月
- 相关性：与大纲章节直接相关
- 权威性：官方文档 > 行业报告 > 技术博客
- 实用性：可转化为教学要点（非纯新闻）
