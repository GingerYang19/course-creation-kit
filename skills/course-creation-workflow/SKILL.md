# 文字稿 → 课程视频 从零制课工作流（编排器）

把一份文字稿（论文稿/博客/方法论文档）做成一讲完整视频课：PPT 课件 + 定稿讲稿 + AI 配音 + 带烧录字幕的 1080p 成片。本技能是**编排器**——不重复各段实现细节，只负责**按序调度子技能、在卡点停下、保证交接产物对得上**。

> 这是**通用版**技能包：不含任何品牌模板/logo/音色。首次使用前请按下方「准备工作」放好自己的模板与素材。

## 何时用

用户拿着一份文字稿要做成课程视频，或明确说"从零做课"。若用户只要其中一段（只做 PPT / 只写讲稿 / 只配音 / 只合成视频），直接用对应子技能，不必启动整条编排。

## 准备工作（首次）

1. **课程 PPT 模板**：把你自己的占位版式模板放进 `assets/ppt-template/`（见该目录 `README.md`）；没有模板则走「通用课程」路径用 `course-outline-to-ppt` 选内置模板。
2. **品牌素材**：logo、吉祥物等放进 `courseware-brand-styling` 技能的 `assets/`（见其 `assets/README.md`），并在该技能里改成你自己的品牌口径。
3. **音色库**：把 `resources/voice_library/` 复制到 `~/.qoderwork/voice_library/`，按其 `README.md` 登记你自己的音色（通用包不含任何预置音色样本）。

## 全景图（四段 + 卡点）

```
⏸ 卡点 A（用户）：需求澄清——受众/目标时长/自录 or TTS/品牌口径/用哪套模板
        ▼
[Stage 1 机器]  文字稿 → PPT 课件
   有自备模板：复制占位版式页改字（规范见下）
   无模板/通用课程：skill: course-outline-to-ppt
   入: 文字稿 .md        出: 可再编辑 PPTX
        │
   ⏸ 卡点 B（用户）：手动优化 PPT，在 PowerPoint 里导出 PDF 回传
        ▼
[Stage 2 机器]  PDF + 文字稿 → 逐页讲稿
   skill: courseware-to-lecture-script
   出: 分页讲稿 .md（页数对齐 PDF，250字/分钟预算）
        │
   ⏸ 卡点 C（用户）：对话贴全文逐页过稿 → 定稿后再做一轮冗余压缩再过稿
        │
   ⏸ 卡点 D（用户）：确认成片方式（A卡点已初定，此处终确认）
        ├─ 自录 → 交付定稿讲稿 + PPT/PDF；若用户自录后要加字幕，
        │         转 subtitled-courseware-video 的"给已有录屏烧字幕"分支
        ▼
[Stage 3 机器]  讲稿 → 配音
   skill: bailian-gen（bl speech）或音色库 tools/ 下的合成脚本
   音色: 音色库 voices.json 挑选，或 cosyvoice 复刻新音色后入库
   ⏸ 卡点 E（用户）：编号试听样本挑音色（复刻音色还须基频核查）
   出: 分页配音 mp3（段间 0.45s 静音，响度归一约 -21 LUFS）
        ▼
[Stage 4 机器]  PDF + 配音 + 讲稿 → 带字幕成片
   skill: subtitled-courseware-video
   ⏸ 卡点 F（用户）：45–60s 烧录预览确认（文字校对+样式确认合一轮）
   出: 带字幕 1080p MP4（可选：自定义片头片尾）
```

## 编排规则（核心）

1. **一次只推进一段，卡点必停。** 每段跑完给交付物 + file:// 链接，明确告诉用户"这一段完成，需要你做 X，做完把 Y 发我"，停止。
2. **卡点等的是用户的产物/决定，不是口头 OK。** 卡点 B 等导出的 PDF；卡点 C 等逐页确认；卡点 E 等音色指定。
3. **页数一条线到底。** 每段开始先核对：PPT 页数 == PDF 页数 == 讲稿页数 == 配音段数 == ASR 数。
4. **体量先算账再动手。** 文字稿字数 → 讲稿约 0.7–0.8 倍字数 → 250 字/分钟估片长 → 15–20 页/讲。超 20 分钟建议拆讲（每讲独立 PPT），在卡点 A 提出。
5. **主观选择不代做。** 音色、PPT 风格取舍、拆讲与否、自录还是 TTS，都出多版/多选项让用户挑。

## 分段执行

### 卡点 A — 需求澄清（AskUserQuestion）
必问五件：①受众与用途 ②目标时长（决定页数/字数预算，是否拆讲）③自录还是 TTS（自录则 Stage 3 取消）④品牌口径 ⑤**用哪套 PPT 模板**（若你备了多套，给每套一句话依据让用户挑，别替他定）。守你自己的品牌禁用词；课件里不出现虚构公司名/人名。

### Stage 1 — 文字稿 → PPT
**有自备模板**：用 `assets/ppt-template/` 里你自己的占位模板。**主路径 = 复制占位页改字**（不是跑脚本）：打开模板 → 按内容挑版式页 → 右键复制整页到工作 deck → 就地改文字，**不动坐标/字号/配色**。每页占位文字都带「≤N 字」上限与备注写死的坐标字号，超限就换版式或删句，别缩字号。模板的说明/规格页交付前删掉。品牌样式规范（配色/字体/logo 位置/吉祥物用法）以 `courseware-brand-styling` 技能 SKILL.md 的「样式」章节为准。若备了多套模板，**一讲之内只用一套，不混用**。
**无模板/通用课程**：先把文字稿蒸馏成大纲，调 `course-outline-to-ppt` 选内置模板。
**内容规范**：视觉极简无 emoji 无导航栏；每页厚实、主副点分层+场景案例/类比条；每 2–3 页至少一处图解/表格；概念用时间线/因果叙事串联。
**字体保真**：中文课件字体要在 rPr 同时写 latin+ea+cs，只改 latin 会残留原字形。
**自检**：soffice 转 PDF + PyMuPDF 拼版逐页目检后再交付。
跑完 →〖卡点 B〗："PPT 初稿完成，请手动优化细节，然后在 PowerPoint 里导出 PDF 发我（PDF 才能字体保真）。"**停。**

### Stage 2 — PDF + 文字稿 → 讲稿　→ 调用 `courseware-to-lecture-script`
入参：定稿 PDF + 原文字稿 + 目标时长。讲稿红线：**忌数字串**（写"三到五份"不写"3-5份"，TTS 读汉字会导致 ASR 对齐错位）；口语化但不刻意；举例与观点顺序忠于文字稿。
跑完 →〖卡点 C〗**对话里贴全文**逐页过稿（不是只给链接）。用户逐页确认后主动提议**冗余压缩轮**：删垫词（我们的/的一个/去进行一个/这样的一个），内容与例子顺序不动，保留口语感，逐页报字数与估时再终稿。**停。**
→〖卡点 D〗终确认自录 or TTS。自录 → 交付讲稿+PPT/PDF 结束（可留"录完给我烧字幕"的钩子）。

### Stage 3 — 讲稿 → 配音　→ 调用 `bailian-gen` 或音色库工具
1. 音色：先读音色库 `~/.qoderwork/voice_library/voices.json`（若不存在，用 `resources/voice_library/` 初始化到该路径；合成工具脚本在其 tools/ 内，含 edge-tts / 百炼 cosyvoice / qwen-audio 三条通道）。要**复刻新音色**：走 cosyvoice 复刻链路（bl CLI 音色复刻，list_voices 定位 target），复刻后登记入 voices.json，男女声都备。
2. 〖卡点 E〗同段试听文本出 3–4 版**编号 mp3** 让用户挑，反馈按"某版+微调"处理；复刻音色若疑不一致，做基频比对给证据。**停。**
3. 合成：按讲稿自然段落分段、段间插 0.45s 静音；成片不传 instruction；语速不匀用 ffmpeg atempo 按字数归一（不变调）；cosyvoice 偏轻末端 +10dB 至约 -21 LUFS；`bl speech` 超时带退避重试约 20 次。

### Stage 4 — 合成带字幕成片　→ 调用 `subtitled-courseware-video`
入参：PDF（300dpi 渲染）+ 分页配音 + 定稿讲稿全文。要点（细节见子技能）：ASR 用 `qwen-audio-3.0-asr-flash-filetrans` 全名，报 Instance pool exhausted 直接换 fun-asr 不重试；字幕文本用讲稿重写 ASR 词级 text；错字进 `subtitle_config.json` corrections（term_case 键不带空格）；改 config 后先删 `{workdir}/*.png` 与 `subs_img/pNN_*.png` 缓存。
〖卡点 F〗先出 45–60s 烧录预览，"文字校对+样式确认"合成一轮。**停。**确认后跑全片。
可选片头片尾：用你自己的品牌素材（logo 扫光 / 吉祥物动画等），ffmpeg concat+白场 fade。
跑完 → present_files 交付 MP4 + srt，报告时长/大小。

## Pitfalls（编排层）

- **别一口气跑完。** 六个卡点全是用户明确要的手动决策点，跳过即做废。
- **卡点 C 只给文件链接不算过稿**；冗余压缩轮别省。
- **Stage 1 别自创构图**——从自备模板里挑现成占位页复制，字超「≤N 字」上限就换版式或删句，**不许缩字号**；多套模板一讲不混用；模板说明页/规格页交付前必须删掉。**Stage 4 别用 soffice 渲染 pptx 出片**（字体回退），必须用用户导出的 PDF——但 Stage 1 自检拼版可以用 soffice。
- **讲稿里数字串**是字幕对轴事故的头号来源，Stage 2 就掐掉。
- **paraformer 别用**（句内线性插值漂移）；非 filetrans 的 flash ASR 不支持文件转写。
- **配音通道按可用性选**：edge-tts 免费且吐词级时间戳（部分网络环境需处理证书/域名，见音色库 README）；复刻音色更贴讲师本人但按量计费、不吐词级时间戳，字幕要另跑 ASR。

## Verification（整体验收）

1. 五件套齐全并有 file:// 链接：PPTX、导出 PDF、定稿讲稿 .md、srt、成片 MP4。
2. 版式零走样：全 deck 只用了一套模板；抽 3 页与模板对应占位页比对坐标/字号/配色一致；无文字溢框或被裁；模板说明页/规格页已删除。
3. 成片时长 == 音频总时长（音画无漂移直接证据）；抽 8 帧裁底部 250px 拼图核对字幕不溢出、对轴准确。
4. 试听开头/中间/结尾各 30s：音色一致、响度约 -21 LUFS、无刻意强调。
5. 品牌零残留（无占位/示例品牌名、无虚构公司名）；字幕术语拼写正确、语气词已清。
6. 六个卡点都真实停下并拿到用户产物/决定。
